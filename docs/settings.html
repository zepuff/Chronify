Reading the marks

Each group in ⚙️ Settings carries a mark, so you can see at a glance what is still missing without opening anything.

MarkWhat it means
✅Everything required in this group is filled in.
⚠️Something is filled in, but a required field is still empty.
—Untouched. Nothing in this group has been set.

Every field has a grey line under it inside the app too. This page is the same text with more room to explain, so you do not have to keep the site open while you fill things in.

PeopleForce

Sends your tracked hours and the daily status into your PeopleForce timesheet. Everything you type here stays on this Mac and goes nowhere except PeopleForce itself.

Company API key required
The key that lets Chronify send your hours and statuses to PeopleForce.
Where to get it: there is one key for the whole company, so paste the one you were given. You do not create your own.
The field is masked. Press Show to check what you pasted, and press it again to hide it.
Employee id required
Your own number in PeopleForce, digits only.
Where to get it: open your own profile in PeopleForce and look at the address bar. It ends in your number, so .../people/12345 means you type 12345.
Working day starts at
The hour your day usually begins, as a number: 9 means 09:00.
Only used when Push real time ranges is off, to decide where the single lump entry starts. With real ranges on, this is ignored.

Each project also needs its own PeopleForce id before its hours can be sent. That one lives with the project, not here. See below.

Daily status

Who turns the rough lines you log during the day into a status you can paste into Slack, and in which language. Chronify installs whichever you pick, so there is nothing to set up by hand.

Written by
Ollama understands Ukrainian and downloads a model of about 2 GB.
Apple Intelligence uses the model already in macOS, so nothing is downloaded, but it cannot write Ukrainian and needs macOS 26 on Apple Silicon.
No AI leaves your notes exactly as you wrote them.
Status language
The language the finished status is written in: English, Ukrainian, Polish.
Your own notes can be in any language, they get translated on the way.

When you pick a writer that is not installed yet, Chronify asks before doing anything, then installs it with Homebrew in the background while you keep working. If a step fails you are told which one, so you can finish it by hand.

Invoicing

Fills your .docx template and produces a PDF in one click at the end of the month. The hours come from the tracker or from PeopleForce; these are the things it cannot work out on its own.

Hourly rate required
Digits only, for example 35 or 27.5.
A project can carry its own rate, and that one wins over this. Use this for your usual rate and set the exception on the project.
Your full name required
Printed inside the invoice as the person being paid, for example Yulia Tymoshenko.
Your name for the file name
Goes into the file name, so keep it to one word. Yulia gives Invoice_Yulia_Client_August_2026.docx.
Client name
Also part of the file name. Short is better; the full legal name belongs in Payment details.
Client code
Short code that starts the invoice number. AMYNEBO for August 2026 gives the number AMYNEBO082026.
Save invoices to
Folder for the finished .docx and PDF. Press Choose… to pick one.
Left empty it falls back to ~/Documents/Invoices.

Payment details

Printed into your invoice wherever the matching {{TOKEN}} sits in the template. Anything left empty stays visible as {{TOKEN}} in the finished document, which is how you spot what is missing.

Quicker than typing: the Import from an invoice… button at the bottom of this group reads all of it out of an invoice you have already sent.

Tax number {{TAX_NUMBER}}
Your own tax number.
IBAN {{IBAN}}
The account the client pays into.
SWIFT / BIC {{SWIFT_CODE}}
Your bank's SWIFT or BIC code.
Your address {{ADDRESS}}
Your address as it should appear on the invoice.
Client legal name {{ACQUIRER_NAME}}
The client's full legal name, exactly as in the contract.
Client address {{ACQUIRER_ADDRESS}}
The client's registered address.
Client VAT number {{VAT_NUMBER}}
Leave empty if the invoice does not need one.
Client NIP {{NIP}}
Polish tax number of the client. Leave empty if your template has no {{NIP}} in it.
Client KRS {{KRS}}
Polish register number of the client. Leave empty if your template has no {{KRS}} in it.

Once you connect your own template, this list is read from that document instead, so a template for another country only needs its own tokens and the fields follow. Nothing in the code has to change.

The invoice template

⚙️ Settings → 📝 Edit invoice template in Word… opens the default template, waits while you edit it, and then connects your saved file.

  • Type your own static details straight into the document. Do not invent new {{TOKENS}}, they are not read from anywhere.
  • Keep the placeholders that are already there, such as {{SUPPLIER_FULL_NAME}} and {{TOTAL_AMOUNT}}, so the automatic values still land.
  • Save as .docx, come back, and press Select saved file.

Word or LibreOffice only. Pages and TextEdit replace the invoice table with plain text when they save, and the finished invoice then has no table at all. Chronify checks for this and tells you rather than producing a broken document.

Project fields

Asked when you add a project, and editable afterwards from ⏱ → 🏷 Project → ✏️ Edit a project.

Project name required
Shown in the menu and printed on the invoice.
Use the same name as in PeopleForce, so the two are easy to match later.
PeopleForce project id
Digits only.
Where to get it: in PeopleForce open Time → Attendance, filter by this project, and take the number out of the address: ...criteria[project_id]=42 means you type 42.
Left empty, this project is never sent to PeopleForce. That is the clean way to track personal work without it reaching the timesheet.
Hourly rate
Rate for this project only, digits like 35.
Left empty, it falls back to the rate in Settings → Invoicing.

Screen Recording

Not a field but a check. ⚙️ Settings → Screen Recording tells you whether window titles are currently readable, and reopens the macOS prompt if they are not.

Without it macOS hides every window title, so the day is logged as bare app names with no task breakdown.

macOS ties this permission to the exact binary. A brew upgrade produces a new binary, so the permission can quietly drop and nothing warns you. If your task names disappear after an update, this is why. Grant it again and restart the app.

Where settings are stored

Everything you type in Settings is written to ~/.work_tracker/profile.json. The defaults live in ~/.work_tracker/config.yaml, and your profile wins wherever the two overlap.

The practical consequence is a good one: upgrades can change the defaults without ever touching what you set. More about the files.
