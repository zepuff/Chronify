Quick start

Ten minutes, then it runs itself

Steps 1 to 4 are everything you need for a working tracker. The rest of the app waits until you use it, and asks for what it needs then.

Install it

You need macOS and Homebrew. Homebrew brings Python and every library with it.

brew install zepuff/chronify/chronify

This takes a few seconds. The formula ships prebuilt libraries, so nothing is compiled on your machine.

Start it

chronify --background

A ⏱ icon appears at the top right of your screen, and your terminal comes straight back. You can close the terminal window, Chronify keeps running.

Without --background the app holds on to the terminal and Ctrl+C quits it, which is handy while you are trying things out.

Allow Screen Recording

macOS asks for this the first time. It sounds heavier than it is: the permission is what lets any app read window titles, and window titles are how Chronify tells one task from another.

Without it your day is logged as bare app names. You get "Google Chrome, 4h" instead of the ticket you actually worked on.

Quit and start Chronify again afterwards. macOS only reads this permission when an app launches, so the switch does nothing until the next start.

If you skipped the prompt, you can reopen it from ⚙️ Settings → Screen Recording, and the same item tells you whether the permission is currently on.

Name a project

Every tracked hour belongs to a project, so nothing is recorded until one exists. Open ⏱ → 🏷 Project → + Add a project.

Only the name is required. The PeopleForce id and the hourly rate can wait until the first time you send hours or make an invoice.

If you work on several projects, add them all now and switch between them from the same menu. Whatever was tracked before the first project existed is adopted by it, so nothing is lost.

Your first day

Nothing else is required. Work as usual and let the clock in the menu bar count. One habit is worth building though, and it takes five seconds at a time.

Every time you finish something, open ⏱ → ✅ What I did today → + Log a completed task and write it however it comes out. fixed the button in safari is enough. Nobody reads these but you, and the evening status is built from them.

Two neighbours are worth knowing about on day one: 🚧 What is blocking me, which becomes its own section of the status until you mark it resolved, and 📋 Plan for today, where anything you do not tick off moves to tomorrow by itself.

Your first evening

Press ⏱ → ✨ Write today's status. Your rough lines come back as text you can paste into Slack, with the tracked hours attached and the blockers listed underneath.

Out of the box the lines are left exactly as you typed them. To have them rewritten into proper sentences, open ⚙️ Settings → Daily status and pick who does the writing:

  • Ollama understands Ukrainian and downloads a model of about 2 GB.
  • Apple Intelligence uses the model already in macOS, so nothing is downloaded, but it cannot write Ukrainian and needs macOS 26 on Apple Silicon.
  • No AI keeps your notes exactly as you wrote them.

Chronify installs whichever you pick, with Homebrew, in the background. There is nothing to set up by hand.

Your notes can be in any language. The status is written in whatever you set under Status language, and the notes get translated on the way.

Start it at login

Once you are happy with it, have Homebrew start it for you:

brew services start chronify

And to stop that again:

brew services stop chronify

What waits until later

Nothing else needs setting up today. Each of these asks for what it needs the first time you open it, and not before:

  • 📤 Send hours to PeopleForce wants the company API key and your employee id. Where to find both.
  • 🧾 Invoice wants your rate, your name and your payment details, and it can read most of that out of an invoice you have already sent. The full list.
  • 🔄 Reload rules only matters once you start editing how windows become task names. How the rules work.

If something looks wrong

The day is logged as app names, with no tasks

Screen Recording is off, or it was granted but Chronify has not been restarted since. Check ⚙️ Settings → Screen Recording: a ✅ means titles are readable, a — means they are not.

The clock is counting, but nothing is recorded

There is no project yet, or tracking is paused. The top of the menu says which: ⏸ Pause tracking means it is running, ▶️ Resume tracking means it is not.

The permission disappeared after an upgrade

macOS ties Screen Recording to the exact binary, and a new version is a new binary. Nothing warns you. Grant it again and restart the app.

The icon is gone from the menu bar

Chronify was quit, or the menu bar ran out of room. Start it again with chronify --background. If your menu bar is crowded, macOS hides the rightmost icons first.
