Quick start

Ten minutes, then it runs itself

Steps 1 to 3 are all you need for a working tracker. The rest are there when you want them, and Chronify asks for them the first time you use something that needs them.

Install it

You need macOS and Homebrew. Homebrew brings Python and every library with it.

brew tap zepuff/chronify
brew trust zepuff/chronify
brew install chronify

brew trust confirms you are fine installing a formula from outside the official Homebrew repo. Without it the install stops with an error about an untrusted tap. The first install takes a while, because Homebrew builds the Python libraries from source.

Start it

chronify --background

A ⏱ icon appears at the top right of the screen. Without --background the app holds on to the terminal window and Ctrl+C quits it, which is handy while you are trying things out.

To have it start when you log in:

brew services start chronify

macOS will ask for two permissions. Screen Recording is the one that matters: without it the window titles are invisible and your day is logged as bare app names with no task breakdown. Grant it in System Settings, then quit and start Chronify again, because macOS only reads that permission at launch. Notifications is the other, otherwise the timed reminders never fire.

Name one project

Click ⏱ in the menu bar, then 🏷 Project → + Add a project. Only the name is required. Until a project exists there is nowhere to put the hours, so tracking stays paused.

That is the whole setup. Chronify is now recording, and the menu bar shows the total for today. Every item in the menu carries a small grey line underneath saying what it does, so you can read the menu instead of a manual.

Pick who writes your status optional

⚙️ Settings → Daily status. Choose Ollama if you want the status written in a different language from your notes, including Ukrainian. Choose Apple Intelligence if you would rather not download a model, and you are on macOS 26 with Apple Silicon. Choose No AI and the status is a plain list of your notes.

Chronify installs whichever you pick, through Homebrew, in the background. Ollama also pulls a model of about 2 GB, so give it a few minutes.

Using it looks like this:

During the day, ✅ What I did today → + Log a completed task whenever you finish something. Write it however it comes out. In the evening, ✨ Write today's status gives you the finished text in a window you can edit, and the Save button copies it.

Connect PeopleForce optional

Three numbers and one key, all from your PeopleForce, all in different places.

Company API key One key for the whole company, issued by whoever administers PeopleForce. Ask them for it, then paste it into ⚙️ Settings → PeopleForce.
Employee id The number at the end of your own profile URL: …peopleforce.io/people/12345 gives 12345.
Project id Open Time → Attendance, filter by the project, and read the URL: …criteria%5Bproject_id%5D=42 gives 42. This one goes into the project itself, under 🏷 Project → ✏️ Edit a project.
Working day starts at Not from PeopleForce. It is the hour a lump timesheet entry is counted from, and you pick it yourself.

After that, 📤 Send hours to PeopleForce → Today sends the hours and the status text. Turn on Auto-push at 00:00 and yesterday goes by itself.

Set up invoices optional

⚙️ Settings → Invoicing takes your rate, your name, the client, and the folder the finished files are written to. Payment details live in their own section, and if you have an invoice you already sent, 🧾 Invoice → 📥 Import details from an existing invoice… reads the IBAN, SWIFT, tax number and addresses straight out of it.

PDF conversion needs LibreOffice, which is free: brew install --cask libreoffice. Without it you still get the .docx.

When the invoice is ready Chronify tells you where it landed and offers to show it in Finder.

Everything you enter lives in ~/.work_tracker/, next to your database and your statuses, and never inside the app folder that Homebrew rewrites on every upgrade. That is also the one folder worth backing up. Open it any time from 📁 Show my data folder.

If something looks wrong

Only app names, no tasks

Screen Recording is not granted. Check it from ⚙️ Settings → Screen Recording. macOS ties the permission to the exact binary, so after brew upgrade chronify you have to grant it again.

Nothing is recorded at all

Look at the icon. ⏸ means tracking is paused and ⚠️ no project means there is no project to record against.

The status is just my notes

The model is not answering. Check ⚙️ Settings → Daily status, and for Ollama that the service is up (brew services start ollama) and the model is pulled.

The invoice has no table

The template was saved in Pages or TextEdit, which flatten the nested table into text. Edit templates in Word or LibreOffice only.
