швидкий старт

Десять хвилин, далі він сам

Кроків з першого по третій достатньо, щоб трекер працював. Решта потрібна тоді, коли захочете, і Chronify спитає про них сам, коли ви вперше скористаєтесь чимось, що їх потребує.

Встановити

Потрібні macOS і Homebrew. Homebrew принесе з собою Python і всі бібліотеки.

brew tap zepuff/chronify
brew trust zepuff/chronify
brew install chronify

brew trust підтверджує, що ви згодні ставити формулу поза офіційним репозиторієм Homebrew. Без нього встановлення зупиниться з помилкою про недовірений tap. Перше встановлення триває довго, бо Homebrew збирає бібліотеки Python з вихідників.

Запустити

chronify --background

У правому верхньому куті зʼявиться іконка ⏱. Без --background застосунок тримає термінал, а Ctrl+C його закриває, що зручно, поки ви пробуєте.

Щоб він стартував при вході в систему:

brew services start chronify

macOS попросить два дозволи. Головний це Screen Recording: без нього заголовки вікон не видно, і день записується самими назвами програм, без розбивки на задачі. Видайте його в Системних налаштуваннях, потім закрийте й запустіть Chronify заново, бо macOS перечитує цей дозвіл лише на старті. Другий це сповіщення, інакше не спрацюють нагадування за часом.

Назвати один проєкт

Клік по ⏱ у рядку меню, далі 🏷 Project → + Add a project. Обовʼязкова тільки назва. Поки проєкту немає, години нема куди писати, тому трекінг стоїть на паузі.

Це все налаштування. Chronify уже пише, а в рядку меню видно сьогоднішню суму. Під кожним пунктом меню дрібним сірим шрифтом написано, що він робить, тож меню можна читати замість інструкції.

Обрати, хто пише статус за бажанням

⚙️ Settings → Daily status. Беріть Ollama, якщо хочете статус мовою, відмінною від мови ваших нотаток, зокрема українською. Беріть Apple Intelligence, якщо не хочете нічого качати і у вас macOS 26 на Apple Silicon. Беріть No AI, і статус буде просто списком ваших нотаток.

Обране Chronify встановить сам, через Homebrew, у фоні. Ollama ще й завантажить модель приблизно на 2 ГБ, тож дайте їй кілька хвилин.

Користуватися цим виглядає так:

Протягом дня ✅ What I did today → + Log a completed task щоразу, коли щось закінчили. Пишіть як виходить. Увечері ✨ Write today's status віддасть готовий текст у вікні, де його можна поправити, а кнопка Save скопіює його.

Підключити PeopleForce за бажанням

Три числа й один ключ, усі з вашого PeopleForce, усі в різних місцях.

Company API key Один ключ на всю компанію, його видає той, хто адмініструє PeopleForce. Попросіть ключ і вставте його в ⚙️ Settings → PeopleForce.
Employee id Число в кінці адреси вашого профілю: …peopleforce.io/people/12345 дає 12345.
Project id Відкрийте Time → Attendance, відфільтруйте по проєкту й подивіться в адресу: …criteria%5Bproject_id%5D=42 дає 42. Це число вписується в сам проєкт, у 🏷 Project → ✏️ Edit a project.
Working day starts at Береться не з PeopleForce. Це година, від якої відлічується сумарний запис у таймшиті, і ви обираєте її самі.

Далі 📤 Send hours to PeopleForce → Today надсилає години й текст статусу. Увімкніть Auto-push at 00:00, і вчорашній день піде сам.

Налаштувати інвойси за бажанням

⚙️ Settings → Invoicing запитає ставку, ваше імʼя, клієнта й теку, куди складати готові файли. Реквізити живуть в окремій секції, а якщо у вас є вже надісланий інвойс, то 🧾 Invoice → 📥 Import details from an existing invoice… вичитає з нього IBAN, SWIFT, податковий номер і адреси.

Для PDF потрібен LibreOffice, він безкоштовний: brew install --cask libreoffice. Без нього ви все одно отримаєте .docx.

Коли інвойс готовий, Chronify скаже, де він лежить, і запропонує показати його у Finder.

Усе введене лежить у ~/.work_tracker/, поруч з базою й вашими статусами, і ніколи в теці застосунку, яку Homebrew перезаписує при кожному оновленні. Це ж і єдина тека, яку варто бекапити. Відкрити її можна будь-коли: 📁 Show my data folder.

Якщо щось виглядає не так

Записуються лише назви програм

Не видано Screen Recording. Перевірте з ⚙️ Settings → Screen Recording. macOS привʼязує дозвіл до конкретного файлу програми, тому після brew upgrade chronify його треба видати заново.

Не записується взагалі нічого

Подивіться на іконку. ⏸ означає паузу, а ⚠️ no project означає, що немає проєкту, на який писати.

Статус просто список нотаток

Модель не відповідає. Перевірте ⚙️ Settings → Daily status, а для Ollama ще й що сервіс живий (brew services start ollama) і модель завантажена.

В інвойсі немає таблиці

Шаблон зберегли в Pages чи TextEdit, а вони перетворюють вкладену таблицю на текст. Редагуйте шаблони лише у Word або LibreOffice.
